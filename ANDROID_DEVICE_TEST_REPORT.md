## 4. Verification Commands for Device Testing (Post-APK Build)

When the APK generated by GitHub Actions (`horizon-android-apk`) is installed on the physical phone:

1. **Install APK via ADB:**
   ```sh
   adb install -r horizon-android-dev.apk
   ```

2. **Launch NativeActivity and monitor logcat:**
   ```sh
   adb logcat -c
   adb shell am start -n dev.horizon.android.dev/dev.horizon.android.HorizonActivity
   adb logcat -s Horizon:V HorizonAndroid:V RustStdoutStderr:V
   ```

3. **Capture FPS and Frame Times via SurfaceFlinger:**
   ```sh
   adb shell dumpsys SurfaceFlinger --latency dev.horizon.android.dev/dev.horizon.android.HorizonActivity
   ```

4. **Profile Memory RSS:**
   ```sh
   adb shell dumpsys meminfo dev.horizon.android.dev
   ```
